# Live QA: patch-by-patch check of R0–R7 (and watch Gates A–B)

Run 2026-09-23 by the supervisor (Claude). Each patch had one reviewer, who checked every finding it claims against `docs/qa/findings.json` and the plan and hunted for new bugs, plus one independent skeptic, who tried to refute every problem and to break every high-severity fix. **Only problems that the skeptic could not refute are listed.** Most were confirmed by running code (vitest, workerd, Robolectric) in a throwaway worktree.

Code refs are at the head each patch was judged on: `origin/main` for R0–R3 (4f98b52), `origin/claude/marc-r0-remediation-ast5xs` for R4–R7 (195caac).

## How to use (remediation agent)

1. Fix in order: **high → medium → low**. Each fix gets a test that fails before and passes after. Reference the QA id (e.g. `QA-R0-1`) in the commit message.
2. Items for the same root cause are grouped under one id. Fix the root cause once.
3. Section **W** belongs to the watch agent. Do not touch it.
4. If you think an item is wrong, say why in `docs/REMEDIATION-PROGRESS.md` with evidence. Don't skip it silently.

### QA-R0-2 · HIGH · new_bug · Hanging up mid-answer escapes every quota counter, because the new disconnect abort means the step is never recorded
