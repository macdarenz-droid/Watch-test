# Supervisor gotchas

One line per incident that a rule would have caught. Newest last.

- **2026-09-29, V1-07 (#96), pinned-test clash.** The V1-07 card changed the figure's drawing, but nobody checked the shared add-only files when the card was written. Two other tasks' blocks pinned the old drawing: FG-6's block in `tests/theme.test.ts` (`bodyPal(t).base === accent`, broken by the Midnight body lift) and FG-4's probe at `scripts/screenshot-gate.mjs:5832-5833` (the drawn load label). They were found mid-build, before review: FG-6 at CHECK-IN 3, FG-4 after the self-check. That cost a re-design round and a blocked PR. Fix: the collision check in `cards.md`, also repeated for each ruling that changes drawn output.
- **2026-09-29, ~14:00 UTC, session-message outage.** One-shot Routines sent to builders failed while the session-message service was down, and builders waited idle. The instruction reached V1-07 only as a PR comment (#96, 14:18). Fix: `tick.md` step 3 (check the Routine's last run, retry once, and post the instruction on the PR when the service fails).
- **2026-09-29, V1-08 (#95), probe sampled a static view.** Probe 1 sampled after the Pictures tab was opened, where the joints do not move. All 17 joints read 0.00° across 1441 samples, so "0 violations" was flat data, and the seeded A2 failure also fired on an unchanged animation. The supervisor accepted it at check-in, and a fresh reviewer caught it at 56b3ced. Fix: accept a probe's numbers only when the probe also shows it saw the thing it measures, and when a no-mutation run shows 0 next to the mutated run.
- **2026-09-30, LIB-26 (#123), a stray `node_modules` symlink reached main.** The builder's stack merge 95aee12 committed a `node_modules` symlink that pointed at a local path. The `.gitignore` line `node_modules/` matches only directories, so it did not catch the symlink. The supervisor checked only the fix commit and its test, not the PR's full diff against main, so the symlink merged at 1a44343. HT-3b's builder removed it on its own branch (c13d84e). Fix: `.gitignore` now says `node_modules`, and before every merge the supervisor reads `git diff --stat origin/main...<head>` for the whole PR, not only the latest commits.
- **2026-09-30/10-01, HT-3b and later How-to cards, size-ceiling collisions.** Several How-to cards each set their own chunk-size ceiling, so cards collided on the same budget. Fix (HT-3c): budgets now live in one shared file, `tests/howto/budgets.json`, instead of per-card constants.
- **2026-10-01, a reviewer was archived mid-review.** A reviewer session was archived before it had posted its verdict, losing the round. Fix: check `post_turn_summary` and the posted verdict before calling `archive_session`.
- **2026-10-01, HT-6 (#112), the classifier refused a budget raise.** Auto mode read a `tests/howto/budgets.json` ceiling raise, which D-HT3c-1 allows, as a test removal, and blocked the builder. Fix: never work around it through any agent. Ask the owner for one approval message in that builder's session, naming the exact entries and values (he approved HT-6's at ~02:45).
- **2026-10-01, builders idle "waiting on CI".** With 15+ runs queued, android-gate waited over an hour, and AUD-1 and HT-5 ended their turns without posting READY. Fix: builders post READY on local checks plus source-gate and visual-gate-tz; the supervisor checks android-gate before merging and nudges idle "waiting on CI" sessions every tick.
- **2026-10-01, ~04:00 UTC, the CI queue outran single merges.** 15+ runs were queued, so one merge per CI cycle could not keep up, and standalone runs on heads that a train now carried still took runners. Fix: merge trains (`tick.md` step 7, HANDOVER 6.8), and cancel runs on superseded heads.
- **2026-10-01, 05:55, AUD-11 (#159), a wrong full SHA in a builder comment.** The FIXED comment printed `caee83f3ea09…`; the real head was `caee83fdf3fa…`, and the supervisor passed the wrong one to the reviewer.
